## Sobre

**HTMLxEditor** é uma IDE Web poderosa que coloca o desenvolvimento Web completo na palma da sua mão.

Com ele, você pode **criar, editar, executar, colaborar, versionar e publicar** projetos diretamente pelo telemóvel, sem precisar sair do aplicativo.

### Principais recursos

- Suporte a **HTML, CSS, JavaScript, TypeScript, JSX e TSX**
- Execução e visualização dos projetos
- Trabalho colaborativo em equipe
- Repositórios para organizar os projetos
- Commits diretamente no aplicativo
- Hospedagem e publicação de sites
- Geração de links públicos

> **Uma IDE poderosa. Sempre no seu bolso.**
